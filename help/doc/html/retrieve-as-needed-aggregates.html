Retrieve as Needed & Aggregates

This example has two DataWindows - both issue the same SQL query. The top DataWindow does not use Retrieve as Needed, while the bottom DataWindow does.

Issue retrieves on both DataWindows by clicking their Retrieve buttons. Compare the retrieval times. For accurate comparisons, retrieve both DataWindows several times.

The time taken to retrieve the bottom DataWindow (which uses Retrieve as Needed) includes the time that it takes to first issue an embedded SQL call to count the number of rows that will be retrieved. The top DataWindow (which does not use Retrieve as Needed) does not need an embedded SQL call initially. The row count is calculated in the DataWindow in a computed field. However, notice that using Retrieve as Needed requires much less time to begin displaying the result set to the user.
