Zip and Unzip Files

This example creates and reads archives with the native CompressorObject and ExtractorObject. When the window opens, a few of the Code Examples files are added to the list and the archive name is set to a file in your TEMP folder (found with the Keyword context service).

Add Files / Clear List
Selects the files to compress.
Compress to ZIP
Calls Compress(files[], archive, ArchiveFormatZIP!). If you enter a password, the Password property is set first and the archive is encrypted with AES-256.
List Contents
Lists the files in the archive with ExtractorObject.GetFilesList. Enter the same password for an encrypted archive.
Extract To Folder
Extracts the whole archive to a folder you select with Extract(archive, folder).
Compress a Blob with GZIP and Back
Compresses a blob in memory with Compress(blob, ref blob, ArchiveFormatGZip!) and restores it with Extract(blob, ref blob, ArchiveFormatGZip!), without touching the file system, and reports the sizes.

CompressorObject and ExtractorObject were introduced in PowerBuilder 2019. They also support 7Z, GZIP and TAR archives.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
