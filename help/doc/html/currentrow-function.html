CurrentRow Function

The CurrentRow() DataWindow function returns the currently selected row in the DataWindow.

For example, this border expression uses the function in the border and background color attributes of the columns to visibly highlight the current row:

If (GetRow() = CurrentRow(), 5, 0)

The background color expression is similar: 

If (GetRow() = CurrentRow(), windowcolor, buttonface)

When the window opens, the computed columns, windowcolor and buttonface, are set to be the value of the current window background color and buttonface color.
