Data Explorer

The Data Explorer is a Windows Explorer-style interface for data manipulation. The explorer consists of two controls linked together: TreeView and a ListView.

The TreeView and ListView controls both display directories in the file system paradigm. The contents of both controls is changed when you select an item in either. The TreeView and ListView controls in this example are populated with data from DataStores. Expand a branch of the TreeView, or double-click an item in the ListView to populate the next level. At the last level (Sales Order items), double-click the item to open an edit window.

Right-click in the ListView to access most of the menu functions.

Menu Options

Open Item
Populate the next level of data. Expand the branch of the TreeView and display the item's children in the ListView.
Edit Item
Open a window to edit the item. Note: this example does not allow changes to be saved.
Line Up Icons
This is valid only when the ListView is in Large Icon or Small Icon view.
