DataWindow Spin Controls

Click a radio button to choose a date spin control or a numeric spin control. Notice that as the data type of the spin control changes, the displayed attributes for it change as well. Use the DropDownListBox mask to apply different edit masks to the spin control.

Use Code Table
Toggles the code table on/off for the spin control. For example, check Use Code Table and spin up or down on the spin control and notice that it scrolls through its associated code table display values.
Spin Increment
The increment or decrement value for the spin control when the up or down arrows are clicked.
Spin Range Min
The minimum value that can be entered in the spin control.
Spin Range Max
The maximum value that can be entered in the spin control.
