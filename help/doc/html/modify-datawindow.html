Modify a DataWindow

This example shows the difference between using Modify() and the direct object reference syntax to change the attributes of DataWindow objects. It also highlights the reasons to use each method.

Using Modify()/Describe()

Describe() is used to obtain the names of all of the objects in the DataWindow. When an object is selected, Describe() is called to obtain the type of object selected. The Modify() syntax is built as objects and attributes are selected. Or you can edit it manually.

To build the Modify() syntax:

  1. Click on a DataWindow object in the first ListBox, or click on an object in the DataWindow. A partial list of attributes for the object appears in the second ListBox.
  2. Choose an attribute from this list to modify its value.
  3. If the selected attribute has a set number of values to choose from, the choices appear in the third ListBox, and the current attribute value is selected. To choose a different value, double-click another item in the third ListBox. If the third ListBox does not contain any items, edit the value manually in the Modify syntax field.
  4. Click Apply to apply the changes to the DataWindow.

Using Direct Object Reference Syntax

The current values of the attributes for the two objects are displayed when the tab page is selected. Direct object reference syntax, not Describe(), determines these values. Select new values and click Apply to apply the changes to the DataWindow.

Note

Notice that the direct object reference tab page lists only two DataWindow objects and four attributes for each of them. Direct object reference syntax cannot be built dynamically, as Modify() and Describe() syntax can. You must know the names of the objects and the attributes being modified when you code the syntax. For this reason, Modify() and Describe() are not obsolete. You still use them to dynamically determine at runtime what attributes of a DataWindow to modify.
