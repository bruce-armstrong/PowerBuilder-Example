TreeView / DataWindow Linking

This example demonstrates using a TreeView control for data navigation and DataWindows to update the data.
The TreeView control is populated with data from DataStores. Each level of the TreeView uses a different DataStore. The level is populated the first time an item is expanded.
The DataWindows on the right of the screen show all records in the path down to the currently selected one. Whenever a DataWindow gets focus, its corresponding TreeView item is selected.
A state picture is used to display a disk icon next to any TreeView item that is changed. This picture is hidden when the data is saved or the changes are canceled.
