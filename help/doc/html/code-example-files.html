The Code Example Files

All files required for the Code Examples are in the Examples directory.

PowerBuilder Solution and Libraries

The Code Examples are a PowerBuilder 2025 solution: open pbexamples.pbsln. Its project, PB Examples.pbproj, lists these libraries. In a solution each library is a folder ending in .pbl that holds one source file per object.

  • PBEXAMFE.PBL - the application object (examples), the main window and the example list
  • PBEXAMD1.PBL - DataWindow objects
  • PBEXAMD2.PBL - DataWindow objects
  • PBEXAMFN.PBL - global functions
  • PBEXAMMN.PBL - menus
  • PBEXAMSY.PBL - DataWindow objects that use database-specific SQL (stored procedures, catalog queries), originally written for SQL Anywhere
  • PBEXAMUO.PBL - user objects
  • PBEXAMW1.PBL - example windows
  • PBEXAMW2.PBL - example windows
  • PBEXAMW3.PBL - example windows
  • PBEXAMNF.PBL - the Modern PowerBuilder examples of features added in PowerBuilder 2017 through 2025 (JSON, REST, encryption, compression, WebBrowser, RibbonBar, PDF Builder and SMTP)

To build the Code Examples executable, deploy the p_examples_exe project in PBEXAMFE.PBL. It builds all the libraries into PBDs, which is required because many of the objects in the Code Examples are used dynamically. The pbexamples_local and pbexamples_cloud projects deploy the examples with PowerClient and PowerServer.

The SVG icons and images the examples use are in the images folder. Files the examples no longer use are kept in _archive.

PowerBuilder Benchmarks Application

The benchmark example runs a separate PowerBuilder Benchmarks application, built from PBEXBM.PBL as a machine-code executable (EXBM_M.EXE) and a Pcode executable (EXBM_P.EXE). Those files are not included in this repository.
