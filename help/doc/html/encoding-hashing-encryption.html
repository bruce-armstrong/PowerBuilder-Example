Encoding, Hashing and AES Encryption

This example uses the native CoderObject and CrypterObject to encode, hash and encrypt text, with no external DLLs or Windows API declarations. Both objects work with blobs, so the text is converted with an explicit encoding: Blob(text, EncodingUTF8!).

Encode / Decode
Shows the text encoded with Base64Encode, Base64UrlEncode, HexEncode and UrlEncode, then decodes the Base64 value back to the original text.
Hash / HMAC
Computes MD5, SHA (SHA1!, SHA256!, SHA512! and SHA3_256!) and an HMAC (HMACSHA256!) keyed with the secret key, shown as hexadecimal.
AES-256 Encrypt + Decrypt
Derives a 32-byte key from the passphrase with SHA-256, encrypts the text with SymmetricEncrypt(AES!, data, key, OperationModeCBC!, iv, PKCSPadding!), and decrypts it again with SymmetricDecrypt.

The initialization vector (IV) in this example is derived from the passphrase only so that the output is repeatable. In real applications use a random IV for each message and store it with the cipher text.

CoderObject and CrypterObject were introduced in PowerBuilder 2017 R3.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
