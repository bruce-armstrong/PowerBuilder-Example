Copy, Move, Discard Rows

Selecting rows
Click a DataWindow row to select it. To select multiple rows, click the starting row; then while pressing and holding the Shift key, click the last row.
Moving rows
Drag the row or group of rows to any of the buffers.
Copying rows
While holding down the Control key, drag the row or group of rows to any of the buffers.
Discarding rows
Press the Delete key to discard rows.
Row counts
Observe the effect of moving, copying, and discarding rows with the displayed row counts. Please refer to the PowerBuilder documentation for the dwRowsCopy, dwRowsMove, and dwRowsDiscard functions to understand how the Update() function is affected when moving, copying, or discarding rows
