DataWindow Functions

Undo
Restores the current row/column value back to its original value that was retrieved from the database.
Select Modified
Highlights all rows on the DataWindow that have been modified.
Reset Modified
Resets the updated flags on the DataWindow, so that the deleted and modified counts are reset to zero. Try changing some data on the DataWindow and then clicking the Reset Modified button. Then click Update. Retrieve the DataWindow again and note that the changes were not made to the database, because the update flags on the DataWindow were reset prior to the update.
