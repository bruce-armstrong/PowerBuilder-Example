OLE 2.0 Control

This example shows how to:

  • Load a file into an OLE control
  • Load a row from the EAS Demo DB OLE table into an OLE control
  • Create a new object in an OLE control
  • Activate the application associated with the data in an OLE control (both in-place and off-site activation)
  • Save the contents of an OLE control as a row in the EAS Demo DB OLE table

To display an object in the OLE control:

  • To load a file into the OLE control, click File > Open File. For example, selecting a BMP or WAV file loads a paintbrush or media player object into the OLE control. An icon in the OLE control indicates if the object has no visual attributes (WAV file).
  • To create a new object with no data, click File > New Object. This displays a list of OLE-enabled PowerBuilder applications in your configuration. (To add an application to the list, see the PowerBuilder documentation.) Copy the contents of an application to the clipboard, then click Edit > Paste to create the object in the application.
  • To load an existing OLE object from the database, double-click in the upper right corner of the DataWindow. When the object is loaded, notice that an image of the object is shown. For objects that cannot be shown (such as WAV files), the application icon is shown instead.

When an OLE object is in the OLE control, you can:

  • Activate the object by double clicking it. If the object supports OLE 2 in-place activation, the object becomes usable within that control, and the menus become the menu of that application. If the object does not support OLE 2 activation, the application associated with that document is loaded outside of PowerBuilder. If you accidentally load a file whose application is not OLE-enabled, a message is displayed when you try to activate. You might need to use REGEDIT.EXE to register your application with Windows. For more information, see the Windows and PowerBuilder documentation.
  • Activate the object by selecting File > Activate (In-place or Off-site). Again, if the object does not support in-place activation, it loads off-site instead.
  • Copy the OLE object to the clipboard by selecting Edit > Copy.
  • Save the OLE object in the EAS Demo DB OLE table by selecting File > Save to Database.
