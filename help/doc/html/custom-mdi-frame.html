Custom MDI Frame

Retrieve
Retrieves the DataWindow on the current sheet.
First
Scroll to the first row of the DataWindow on the current sheet.
Next
Scroll to the next row of the DataWindow on the current sheet.
Prior
Scroll to the previous row of the DataWindow on the current sheet.
Last
Scroll to the last row of the DataWindow on the current sheet. The following options will only be available for the Customer List:
New
Inserts a new row in the DataWindow on the current sheet.
Delete
Deletes the current row of the DataWindow on the current sheet.
Apply
Updates the DataWindow on the current sheet.
