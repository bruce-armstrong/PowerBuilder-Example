Copy DataWindow

This example shows five different ways to get data into and out of DataWindows. Each test is timed, so that you can see the performance differeces of each method when you run it.
Copy Using GetItem/SetItem
This method uses the appropriate GetItem function (such as GetItemString(), GetItemNumber(), and GetItemDate()) to get the data for each row. It then calls InsertRow() to insert a new row into the second DataWindow, and SetItem() to set the data.
Copy Using ClipBoard
This method saves the data to the Clipboard using SaveAs(), and then imports it into the second DataWindow using ImportString().
Copy Using Structure Array
This method uses the DataWindow object reference syntax to copy all the data into an array of structures that matches the data types of the columns. Then copies the data from there into the second DataWindow.

This is the fastest method to use if you manipulate the data in any way: dump the data into the structure array and loop through it making the necessary changes, then copy it back. This is much faster than stepping through each row of the DataWindow.

DataWindow to Structure Utility example
This example hows how to automatically create a global structure or an autoinstantiated Custom Class NVO that matches the DataWindow.
Copy Using Direct Reference
This method is similar to the previous one, except that it saves one step: the syntax allows you to directly copy all data from one DataWindow to another with one statement, which is faster.
Copy Using RowsCopy()
This method uses the RowsCopy() function, which is the fastest way to copy data from one DataWindow to another.
