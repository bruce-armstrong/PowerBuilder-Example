PSR (Report File) Viewer

Click Select PSR File to open a file selection dialog box. Choose any .PSR file to load it into the DataWindow. PSR files contain both the DataWindow definition and data.
You can treated the loaded PSR file as a normal DataWindow, except that the database connection does not exist.
To create new .PSR files, use the SaveAs( ) function or menu options with viewing DataWindows.
You can save composite and Nested Report DataWindows as PSR files. The examples directory includes one PSR, comprep.psr and nestrep.psr, of each type.
In PowerBuilder 8 and later releases, a DataWindow can have buttons with predefined actions . These buttons are also active in a PSR. The examples directory includes two reports that use buttons: btnmaint.psr and btnrept.psr.
