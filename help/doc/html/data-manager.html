Data Manager

The Data Manager is an improved Windows Program Manager-style interface for data manipulation. The Data Manager is an Multi-Document Interface (MDI) application with a ListView control on each sheet containing data from the database.

The difference between the Data Manager and the Window Program Manager is that items in the Data Manager can be viewed in any of the four ListView styles (Large Icon, Small Icon, List, and Report). In addition, the Data Manager is used to drill down to other data. This would equate to having groups within groups in Windows. Actually, these differences make the Data Manager more like the Macintosh Finder than the Windows Program Manager.

The ListView controls in this example are populated with data from DataStores. Double-click an item in one ListView to populate the next level. At the last level (Sales Order items), double-click the item to open an edit window. Right-click in the ListView to access most of the menu functions.

Menu Options

Open Item
Populate the next level of data. Expand the branch of the TreeView and display the item's children in the ListView.
Edit Item
Open a window to edit the item. Note: this example does not allow changes to be saved.
Line Up Icons
This is only valid when the ListView is in Large Icon or Small Icon view.
Auto Arrange
This is only valid when the ListView is in Large Icon or Small Icon view.
Minimize on Use
The Data Manager frame will minimize whenever any item is opened for editing.
Default View
This is the ListView style that will be used on all new windows which are opened.
