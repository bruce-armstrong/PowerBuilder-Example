Tab Control Phone Directory

This example demonstrates two different ways to create a Customer Phone Directory using the PowerBuilder Tab Control:

  • Using a single DataWindow and tab pages on the Tab control to filter the DataWindow.
  • Using a User Object with a DataWindow as the tab pages on the Tab control and retrieving the data when that object is displayed.

The directory displayed when the window is opened uses the single, floating DataWindow. When you select each letter, the DataWindow is filtered to display only the names starting with that letter.

Click User Objects to show the other Tab control. This one consists of tab page user objects (u_tab_dir) that each contain a DataWindow with a retrieval argument. When a page is selected, that DataWindow is retrieved. However, the retrieval is only done once. Notice that the pages are displayed much faster when selected a second time.

Click Change Tabs to position the tabs somewhere else on the Tab control.
