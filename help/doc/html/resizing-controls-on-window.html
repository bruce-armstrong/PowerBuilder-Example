Resizing Controls on a Window

Drag the lower right corner of the window to resize it.
Notice that controls like radio buttons and check boxes do not resize properly, because their size is fixed. However, you can resize their text. To resize DataWindows, set the zoom attribute. You can resize all controls by setting their x, y, width, height and fontsize (if the control has a text attribute) attributes; by calculating a new ratio (new window size/old window size); and then applying that to the original attributes of the controls. Look at the window function wf_resize_it( ) to see exactly what happens.
