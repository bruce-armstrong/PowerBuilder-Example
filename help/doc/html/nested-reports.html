Nested Reports

Opening the reports
Open the various nested reports from the File menu. The File menu also contains menu items to close or print the active report.
Navigation and display of reports
To view the entire report, choose one of the Page commands in the Display menu or in the report's context menu. To scale the display area of the report, choose a Zoom command in the Display menu or in the report's context menu. To display rulers for the report, click Display > Rulers.
