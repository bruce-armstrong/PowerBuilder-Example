PopulateError Function

This example demonstrates the use of the PopulateError function to populate the error object. It asks you to enter some values, validates them, and populates the error object with any error message. It then uses the SignalError function to trigger the SystemError event to display the message.

The PopulateError function sets the error number and error message text properties of the error object. The SignalError function can then be used to trigger the SystemError event. You must code the SystemError event to process the error. The Code Examples SystemError event opens a window that displays the properties of the error object. It includes buttons to exit the application or continue.
