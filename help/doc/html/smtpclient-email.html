Sending Email with SMTPClient

This example sends email directly to an SMTP server with the native SMTPClient and MimeMessage objects. No MAPI client or mail program is required.

Server settings
Set the Host, Port and EnableTLS properties for your server, and UserName and Password if it requires authentication.
Message
The message is built through the Message property (a MimeMessage): SetSender, AddRecipient, Subject, and either HtmlBody or TextBody, depending on the Send body as HTML option.
Send
Calls Send() and shows the result. A negative return value is an SMTPClient error code; see SMTPClient in the PowerBuilder help.

To try the example without a real mail account, run a local test mail server such as smtp4dev or Papercut (for example in a Docker container) and send to localhost.

SMTPClient was introduced in PowerBuilder 2022 R2. It also supports attachments, asynchronous sending (SendAsync) and OAuth 2.0 (XOAUTH2) authentication.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
