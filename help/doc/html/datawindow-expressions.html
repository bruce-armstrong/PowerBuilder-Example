DataWindow Expressions

This example demonstrates the following DataWindow expressions: 

LIKE 
IN 
BETWEEN 
RGB 
CASE

This example demonstrates using these expressions in the text.color attribute of the columns on the DataWindow:

  • Enter a portion of a name (for example, %ar%). All names that match change to red.
  • Enter a salary range (like $30,000.00 to $40,000.00) All salaries between those numbers change to yellow.
  • Enter a list of IDs separated by commas (for example, 1751, 191, 750). All IDs in the list change to blue.
  • Enter numbers between 0 and 255 for the three RGB function values. A CASE expression is used to change the appropriate status to the calculated color.
