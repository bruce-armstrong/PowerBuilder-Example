DropDownDataWindow Techniques

Retrieve and Insert Row operate on the main DataWindow.

The DropDownDataWindow (DDDW) used in this example is for the Manager ID column. The contents of the DDDW changes depending on the current row: it lists employees only in the current department.

To change the dataobject of the DDDW, click the Employee Partial Detail and Employee Full Detail buttons. The Employee Partial Detail DDDW shows only Employee ID, Name, and Department ID. The Full Detail DDDW additionally shows the employee salary and social security number.

Click Sort or Filter to specify sort or filter criteria for the DDDW.

Example

Click Retrieve. Click the Manager ID column of department 200 and observe that it lists only employees who work in department 200. Changing rows changes the contents of the DDDW. Click Employee Full Detail to change the dataobject of the DDDW. Click the Manager ID column again, and notice that the DataWindow changes, now showing the employee's salary and social security number. Click Sort and specify a different sort order for the DDDW (such as Employee ID or salary). Click Filter and specify filter criteria for the DDDW (such as salary > 30000).
