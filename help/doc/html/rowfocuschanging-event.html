RowFocusChanging Event

The RowFocusChanging event is similar to the RowFocusChanged event (it fires whenever focus changes from one row to another in a DataWindow) except that it fires before the focus changes and can prevent the focus from changing. The example validates the data entered for the Sales Order items in the RowFocusChanging event and if the data fails focus remains on the invalid row.

Validation Rules

  • A Product ID must be selected.
  • The Ship Date must be greater than or equal to the Order Date.
  • The Quantity must be greater than 0.
