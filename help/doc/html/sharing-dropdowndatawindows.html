Sharing DropDownDataWindows

This example uses three DropDownDataWindows:

  • Customer
  • Sales Representatives
  • Financial Codes

The minimized window contains the three DataWindows that are used for the DropDownDataWindows.

To share data between the primary DataWindows on the minimized window with the secondary DropDownDataWindows, click the checkbox. To stop sharing data, click the checkbox again so that it is not checked.
