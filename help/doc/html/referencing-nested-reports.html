Referencing Nested Reports

This example shows how to directly reference columns and their data in a nested or composite report.

The report shown is a nested report of all employees and their salaries for each department. Enter a raise percentage for each employee making more than the department average and another percentage for each employee making less. Click OK to see the results, including new total salaries for each department.

Use the >> button to page forward and the << button to page backward in the report.
