Function Overloading

PowerBuilder allows function overloading at the object level. This example uses a Global Replace function to show how to overload window functions.

Syntax

The function call used is determined by the values entered. The syntax is displayed at the bottom of the screen. The Global Replace function is called as follows:

of_global_replace( source, old, new {, usecase} {, start, end} )

Arguments

source
A string containing the text to be changed. Passed by reference.
old
The string to be replaced.
new
The new string to replace it with.
usecase
A boolean indicating whether the replace is case sensitive (optional).
start
An integer indicating where the search begins (optional)
end
An integer indicating where the search ends. The default is Len(source) (optional)

Return Value

Integer. Returns the number of occurrences of old that are replaced by new.
