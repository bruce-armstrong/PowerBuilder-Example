Trackbar Controls

This example demonstrates horizontal and vertical trackbars.

Drag the slider on either trackbar to zoom the DataWindow in and out. Try setting various options in the Options groupbox and see how it affects the trackbar controls.

Options

Line Size
How far the slider moves in response to keyboard input from the arrow keys.
Page Size
How far the slider moves in response to keyboard input from the PageUp or PageDown keys or the mouse. When PageSize is set to 1 the slider moves 1 increment in the range of values
Start Position
Where the slider is when you open the window.
Min Position
The beginning of the range of values.
Max Position
The end of the range of values.
Slider Size
The size of the slider and the width of the trackbar.
Tick Frequency
How frequently tick marks display.
Tick Position
Where the tick marks display.
Slider
Unselect to hide the slider.
