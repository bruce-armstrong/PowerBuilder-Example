Text Style Changer

Ancestor user object
B Change the text to bold

I Change the text to italic

U Underline the text

Inherited user object

B The ancestor script has been overriden. When clicked, instead of making the text bold, this button changes the text to 'bold is not allowed'. Click the button again to change the text back to its original value.

I The ancestor script has been overriden. The descendant script executes and checks to see if the text is 'please'. If so, the descendant script dynamically executes the ancestor script to make the text italic.

U The ancestor script has been extended. Therefore, the ancestor script executes first and underlines the text. Then, the descendant script executes and inverts the colors of the text
