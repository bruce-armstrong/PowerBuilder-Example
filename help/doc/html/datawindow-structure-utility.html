DataWindow to Structure Utility

The DataWindow direct object reference syntax allows you to move all the data in the DataWindow with one statement. You can copy data to or from an array of a structure that matches the DataWindow's data structure. This is the fastest way to get data from, or put data into, a DataWindow. See the Copy DataWindow example for an example of using this feature.

This utility automatically creates a global structure or an autoinstantiate Custom Class NVO that matches the DataWindow. You can then import the object into a PBL and use it.

Click Select PBL to choose the library. Both kinds of library are supported:

  • A workspace library: select the .pbl file. The DataWindows are listed with LibraryDirectory and read with LibraryExport.
  • A solution library (PowerBuilder 2025 and later), which is a folder ending in .pbl that holds one source file per object: select the .pblmeta file inside the folder. The DataWindows are listed from the folder's .srd files and read from their source.

This is also useful for Distributed PowerBuilder. You cannot pass a DataWindow using Distributed PowerBuilder, which allows you to pass only simple data types to the distributed objects. However, you can pass the data in the DataWindow in a structure array.
