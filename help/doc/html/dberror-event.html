DBError Event

Click a radio button to choose how error messages are handled when a database error occurs for the DataWindow.

Click Retrieve to retrieve data into the DataWindow.

Enter data into the DataWindow that will cause a database error when the Department table is updated. For example, add a new row, and fill in the Department Name and Manager ID columns, but leave the Department ID blank.

Click Update. When the Update function fails, the dberror event of the DataWindow is triggered and the appropriate action is taken, based on how you choose to handle error messages. If you choose the default error message, the DataWindow Error message is displayed. The customized message for this example shows the database-specific error code and message that occurs.
