Including Blob Columns in a Data Pipeline

You can include Binary Large Object (BLOB) columns in a Data Pipeline. In the Pipeline painter, paint the SQL statement for all other columns first. Then, click Design/Database Blob in the menu to add the blob column.

This example creates a copy of the OLE table, which includes a blob column (the OLE object itself).

Click Execute Pipe to create and load the new table. As the pipe executes, the number of rows read and written is displayed. When it is done, the DataWindow shows the data from the new table.

This example also includes an OLE 2.0 object in a DataWindow. Double-click any OLE object in the DataWindow to activate it.
