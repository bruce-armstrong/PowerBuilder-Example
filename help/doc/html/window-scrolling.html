Window Scrolling

Scroll Lines Per Page
This value determines the number of lines on a page for the window. It affects the number of PowerBuilder units the window scrolls when you click inside the vertical scroll bar.
Units Per Scroll Line
This value determines the number of PowerBuilder units that the window scrolls when you click the up or down arrow of the vertical scroll bar. The default value (zero) scrolls the window 1/100th of the window height when you click the arrows.

Example

Try decreasing the scroll units per line, and click Apply for your changes to take effect. Click and hold the up or down arrow on the scroll bar, and notice that the window scrolls a lesser amount. Increase the scroll units per line, and notice that the window scrolls a greater amount.
