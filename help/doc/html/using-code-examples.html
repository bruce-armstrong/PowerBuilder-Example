Using the Code Examples

The PowerBuilder Code Examples front end is divided into two main parts: The left side of the screen includes the list of all examples, while the right side of the screen displays information about the currently selected example.

Examples List

The Code Examples window lists available examples in a TreeView. Examples are grouped into categories, like DataWindows and Functions. Examples can appear in more than one category. In addition to the main Examples page, the Tab control has a Search page.

Showing New and Changed Examples

In the Examples page, you can view all examples, or use the DropDownPictureListBox to filter examples by their status. Each example is listed with one of these status symbols:

Examples marked with this symbol are part of the original set of code examples and have been changed only where necessary to replace obsolete syntax.
Examples marked with this symbol have been changed significantly in subsequent releases.
Newer examples are marked with this symbol.

Choose Modern (2017+) in the list to show only the examples of features added in PowerBuilder 2017 and later. These examples are also grouped under the Modern PowerBuilder category, and none of them require the demo database.

Searching the Code Examples

The second tab page is used to search for examples. You can search for examples that:

  • Use one or more specified events
  • Use one or more specified PowerScript functions
  • Use one or more specified user-defined functions
  • Reference one or more specified objects

Data Explorer Display

When you select an example in the TreeView, information about the example is displayed in the Data Explorer on the right side of the window. Data Explorer has two tab controls:

Description/Techniques
Describes the functionality and techniques used in the example.
Related Objects
Contains a TreeView with cross-reference and metaclass information all the objects used in the example. You can navigate the tree to nested objects and all scripts. In a script, double-click any event or function to open a window and view its code.

Menu Items

You can access many of the menu commands by right-clicking items in the Examples list.

File

Example Report
Shows a printable report of all the example information for the currently selected example.
Go To Topic
Scrolls to the first example of the selected topic.
Change Database Connection
Opens a window where you can change the connection information for the EAS Demo database.
Run!
Runs the selected example. You can also click Run! in the menu, or double-click an example in the list to run it.

Help

Contents
Opens the topic, PowerBuilder Code Examples.
Using the Code Examples
Opens this help topic.
Current Example Help
Opens help for the currently selected example.
About Displays information about the Code Examples.

Note

Configuration information for the Code Examples is stored in the registry rather than the example.ini file. It is stored under HKEY_CURRENT_USER\Software\Appeon\PowerBuilder\version\Code Examples. You can view this information with the Registry Editor example included.
