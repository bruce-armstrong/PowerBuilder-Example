PowerBuilt Notepad

To create a new document, click File > New in the menu or the New toolbar button.

To open a text file, click File > Open or the Open button.

To delete a file from disk, click File > Delete.

To save a document to disk, click File > Save or the Save button.

To print a document, click File > Print or the Print button.

The standard text editing and manipulation functions (cut, copy, paste, and so on) are in the Edit menu and toolbar buttons. The context menu also has Edit commands.

To find and select specific text in the document or jump to a specific line number, click Search and choose a command.

Click Options to choose various options. The status indicator shows the current text line and column. The clock displays the date and time.
