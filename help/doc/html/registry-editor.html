Registry Editor

This example is a Windows Registry Editor. It uses a PowerBuilder TreeView and ListView control and Registry functions (RegistryGet, RegistrySet, RegistryDelete, RegistryKeys, and RegistryValues) to display and update the registry.

It also demonstrates the basics of using a TreeView control. The first level of the tree is added in the window open event. Afterward, each additional level is added when necessary. The code is in the ItemPopulate event of the TreeView. ItemPopulate is fired once for each item in the tree (the first time it is expanded). Recursion is used to determine the full path to the current item.

This example also demonstrates linking a TreeView control with a ListView control, as used in the Windows Explorer.

Configuration information for the code examples is stored in the registry rather than the example.ini file. The branches to this information are opened when the example is started.

Please note: because the registry contains important system settings, exercise extreme caution when updating your registry. It is highly recommended that you confine changes made when running this example to these branches.

Usage

Click on a folder to view the Registry entries and values for that key.

Double-click a folder, or click the + symbol next to it, to view its sub-folders.

Click twice (do not double-click) on a key or entry to change its name, or click Registry > Rename.

Double-click an entry or click Registry > Modify Value to change the value for an entry. Click Registry > New > Key to add a new sub-key under the currently selected key. Click Registry > New > Value to add a new entry to the currently selected key. Press Delete (or click Registry > Delete ) to delete the currently selected key or entry.
