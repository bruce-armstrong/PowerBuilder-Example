Item Status & Updating

Notice that the row status of each row in the DataWindow is shown to the right. The status of the current column is shown at the bottom of the window.

In the DataWindow, you can change the item status for rows and columns in two ways: by clicking Rows/Insert Row in the menu to modify data and insert rows, or by explicitly using the SetItemStatus() function.

Experiment with item status by changing the data on both original and new rows in the DataWindow. Notice that as you change the item status of a column, the row status changes as well.

You can apply the SetItemStatus() function to an individual column or an entire row. To apply SetItemStatus() to a column, right-click in the column of the row whose status you want to set, and choose the item status. To set the item status for an entire row, right-click on the row status text (on the right side of the DataWindow) and choose the item status. Options are disabled if they are invalid for the current row status.

To see how item status in a DataWindow affects the Update statement, click Rows > Update Syntax, and step throught the generated SQL syntax. The row focus indicator of the DataWindow moves to the row that corresponds to the generated SQL statement. An Update statement is generated for any modifed rows, and an Insert statement is generated for any new rows that were modified. Delete statements are generated for any of the original rows that were deleted.
