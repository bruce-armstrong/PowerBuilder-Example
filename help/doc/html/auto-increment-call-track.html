Auto Increment - Call Track

This is an example of using an auto increment column in a table. It is a simple add/update/delete window to maintain data in a table used to track calls.

The id column of the call_track table is set to have a default of AutoIncrement. This allows the database to automatically increment the number whenever a new row is added. There is no need for PowerScript code to determine the call id.

  1. Click on any row in the Call List (bottom) DataWindow and see the full information about that row displayed in the top DataWindow. You can update and delete this data as you would with any other DataWindow.
  2. To add a new record, click Add Record. This opens a blank record in the top DataWindow. Notice that there is no number in the Id column. This value will be calculated by the database when the data is saved with the Save Updates button.
