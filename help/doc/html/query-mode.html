Query Mode

When the upper DataWindow is in Query Mode, you can type criteria for the retrieval in the column fields.

Items placed in the same row use And by default. Each additional row of criteria uses Or by default.

You can change the defaults by explicitly stating and/or in front of the criteria.

As you type the criteria, notice that tabbing out a field adds the criteria to the SQL statement on the bottom. Clicking Retrieve also accepts the criteria in the field you are typing in.

QueryMode Examples
ID State WHERE Clause
1 Id=1
<1 TX Id < 1 and State = 'TX'
2 < 9 TX (id = 2 and State = 'TX') or Id < 9
<10 and > 2 (id < 10 and id > 2)
