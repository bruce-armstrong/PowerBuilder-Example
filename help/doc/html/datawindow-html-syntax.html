DataWindow to HTML Syntax

Select a DataWindow and click Browse. The data is saved in an HTML table or form, and displayed in a Web browser. To choose the browser, click the Select Browser button.

This example uses the DataWindow HtmlTable attribute and GenerateHTMLForm function to save the HTML syntax. To use the table syntax, click Save Rows As > HTML Table for a DataWindow. Note: This action does not work for Nested and Composite reports.

HTML Options

HTML Options Table
These options change DataWindow attributes , using either the Modify function or object reference syntax. Note: not all of these options work with all browsers.
Create Style Sheet
Creates a Cascading Style Sheet (CSS) file that preserves the text styles (such as font face, size, and weight) of the DataWindow, separately from the HTML code.
Wrap Text Within Cells
Creates fixed-width cells that wrap text within the cells, instead of automatic adjusting cell width.
Table Width
The width of the entire table (the HTML table width attribute).
Border Width
The width of the border. 0 indicates no border.
Cell Padding
The space around the text within each cell.
Cell Spacing
The space between cells.
Form
These options are passed as arguments to the GenerateHTMLForm function.
Start Row
The first row of data in the DataWindow to display in the form.
End Row
The last row of data in the DataWindow to display in the form.
Start Column
The first DataWindow column to include in the form.
End Column
The last DataWindow column to include in the form.
Buffer
The DataWindow buffer from which to retrieve the information.
