Placeholders and OpenURL

This example shows two small conveniences: placeholder hints in input fields, and opening links in the default web browser.

Placeholder property
The SingleLineEdit, EditMask and MultiLineEdit controls set the Placeholder property. The hint is shown while a field is empty and does not have focus, which can replace a separate label. For an EditMask, placeholders work with string masks only.
Fill In / Clear
Fills the fields with values (the placeholders disappear) or clears them again.
OpenURL buttons
Call OpenUrl(url) to open a web page, or a mailto: link that uses the e-mail address entered, in the default browser or mail program. OpenUrl replaces the obsolete Inet.HyperlinkToURL function.

Placeholder support for EditMask and MultiLineEdit was added in PowerBuilder 2025; OpenUrl was added in PowerBuilder 2022 R2.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
