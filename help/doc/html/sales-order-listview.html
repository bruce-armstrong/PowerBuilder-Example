Sales Order ListView

This example demonstrates the features of the ListView control in an application to add a sales order.

  • Enter the sales order information and drag products from the Products window and drop them on the sale order items area.
  • Double-click a product to view or edit it.
  • Right-click in the Product window to change the view.

Buttons

New Order
Get the next order number and display a blank screen.
Add Items
Open the Products window.
Delete Item
Delete the currently selected item from the sales order.
Update
Save the order.
