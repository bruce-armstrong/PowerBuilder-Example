Performance Benchmarks

The Performance Benchmarks include 11 tests of PowerBuilder functionality that demonstrate various levels of improvement using machine-code compilation. The source of the application being executed is pbexbm.pbl, in the Code Examples directory.

Note about benchmarks: The performance benchmarks included here are intended only as a comparison of p-code and machine-code compilation. Because they are run from the Code Examples, you might not get the same results every time. For the most accurate results, run the two executables (pbexbm_p.exe and pbexbm_m.exe) individually. You will also get more accurate results if nothing else is running on your computer at the same time, and you disable any network connections.

  1. Click Execute P-Code Benchmarks to launch pbexbm_p.exe, the benchmark application compiled into p-code.
  2. Click Execute Machine-Code Benchmarks to launch pbexbm_m.exe, the benchmark application compiled into Machine-Code.
  3. Click Report >> to display a report of the results.
