Column Text Value vs. Item Value

Change the data on any column of the DataWindow. Note that as the data is being changed, the text value of the column changes as well.

To apply the text value of the column to the underlying item value of the column, tab to another column or click AcceptText. Tabbing to another column causes an itemchanged event to occur on the DataWindow, applying the text value (edit field) of the column to the item value. Tab back to the column that was changed, and note that the item value of the column has been changed to the value that you entered.

Clicking AcceptText calls the AcceptText function, programatically applying the edit field to the underlying item. Note that the item value of the column is modified.
