Running the Performance Benchmarks

The title bar displays the type of executable currently being executed.

Click the button for any test to execute it. Except where noted (see The Benchmark Tests), iterations refers to the number of times a test is run.

Click Run all tests to perform all 11 tests.

Set Machine ID
Allows you to save information about the machine performing the tests (CPU, speed, memory) which will be displayed on the report.
Save Results
Saves the results to the Windows Registry.
Report
Produces a report of the test results.
