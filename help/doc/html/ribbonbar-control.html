RibbonBar Control

This example builds a ribbon with the RibbonBar control. A ribbon organizes commands into Categories (tabs), each containing Panels of large buttons, small buttons, check boxes and combo boxes. Each button is bound to a user event of the RibbonBar by name; the event receives the handle of the clicked item, and this example writes the button text to the log.

Build with Script
Removes all categories (GetCategoryByIndex and DeleteCategory) and builds the ribbon item by item with InsertCategoryLast, InsertPanelLast, InsertLargeButtonLast and InsertSmallButtonLast. The click handlers use GetLargeButton and GetSmallButton to get the clicked item.
Load from JSON
Replaces the ribbon with one described as JSON, using ImportJSON. Ribbons can also be loaded from XML or from files.
Show ExportJSON()
Shows the JSON description of the current ribbon, which can be saved and loaded again later.

Ribbons can also be designed visually with the RibbonBar Builder. In PowerBuilder 2025, an existing MDI menu can be displayed as a ribbon without code changes.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
