Change Employee Salary

Select a Department, Start Date, and Status and enter a raise or reduction percentage.

Click Highlight Employees to Change to highlight the rows in the DataWindow that match the criteria. Use PowerBuilder direct object reference syntax, not Describe(), to determine which rows are affected. Also use direct object reference syntax of instead of Modify() to change the attributes of the rows.

Click Calculate Employee Salaries to change the salary column for those rows. Again, use direct object reference syntax instead of Describe() to determine which rows to change. Also use direct object reference syntax instead of GetItemNumber() and SetItem() to change the salaries. Click Reset Data to return the data and DataWindow to their original state.
