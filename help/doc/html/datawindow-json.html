DataWindow ExportJson and ImportJson

This example converts DataWindow data to JSON and back. The source DataWindow on the left contains embedded employee data, so no database connection is needed; the target DataWindow on the right starts empty.

Export Plain JSON
Calls ExportJson(), which produces plain JSON: an array with one object per row, keyed by column name.
Export DataWindow JSON
Calls ExportJson(True), which produces DataWindow JSON. This format also carries the DataWindow identity, the row and column status flags and the original values, so updates can be reproduced elsewhere (for example by a PowerServer Web API).
Changed Rows Only
Calls ExportJson(Primary!, True, False) to export only rows that have been modified. Change a value in the source DataWindow first.
ImportJson
Resets the target DataWindow and calls ImportJson(json, error) with the JSON shown. Both JSON formats can be imported; JSON keys are matched to column names.

ExportJson and ImportJson were introduced in PowerBuilder 2017 R3.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
