Evaluate / ItemError

Describe(Evaluate), ItemError event, SetActionCode( )
In the salary field, type a mathematical expression. The expression is evaluated when you leave the field.
Example 1
If the salary field currently shows 50,000.00, click the end key to move the cursor to the end of the field and type *2. Click Enter: the salary is doubled.
Example 2
Move to a new field. Begin typing an expression, such as (20*(1575+5433)). Click Enter. The expression is evaluated using the correct math precedence.

The item is evaluated in the ItemError event, because the math expression is a string and the field is a numeric data type.

Note: The field also has a validation rule that the salary must be greater than zero. If it contains a math expression, the DataWindow field validation is still executed after the math expression is evaluated. This is accomplished by placing the evaluated expression result using SetText() in the post event of the ItemError.
