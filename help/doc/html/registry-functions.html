Registry Functions

This example demonstrates the use of the PowerBuilder functions to manipulate data in the Windows Registry. It highlights the use of functions to read and write data other than strings.

This example uses the RegistryGet and RegistrySet functions, overloaded with the data type being read.

Valid types include:

  • String
  • ExpandString - a string including unexpanded references to environment variables
  • Binary
  • ULong
  • MultiString - an unbounded array of strings
