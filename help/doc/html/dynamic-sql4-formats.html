Dynamic SQL: 4 Formats

Format 1 Example
Use the DynamicSQL menu to create a new table named Locations in the database. After it is created, the table name appears in the list of tables. Choose Alter from the menu to add a fax column to the Locations table. Choose Drop from the menu to drop the Locations table (if not, the table will automatically be dropped when the window is closed).
Format 2 Example
This is a simple example of building a dynamic update statement. First, select a department. Then, choose a new manager name and whether to have benefits for the employees in the department. Click DynamicSQL > Execute to issue the dynamic UPDATE statement.
Format 3 Example
Choose a department from the ListBox of departments. The employees that work in the current department are listed.
Format 4 Example
  1. Enter a dynamic SELECT statement (or keep the default statement provided).
  2. Click DynamicSQL > Describe to prepare the dynamic staging area with the dynamic SQL statement specified and describe the dynamic staging area into the dynamic description area.
  3. Next, enter values for the input parameters. The order of the input parameters that you enter must match the order of the input parameters specified in the dynamic SQL statement.
  4. Click DynamicSQL > Execute to open a dynamic cursor that is already associated with the dynamic staging area. Each row is fetched using the dynamic description area, and the output parameters of the dynamic description area are shown.

Note

All the formats use MicroHelp to display many of the dynamic SQL statements that are executed.
