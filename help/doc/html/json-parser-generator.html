JSONParser and JSONGenerator

This example shows how to read and write JSON with the native JSONParser and JSONGenerator objects, without parsing strings by hand. A sample JSON document is loaded and parsed when the window opens.

Parse into Tree
Loads the JSON text with LoadString and walks it recursively from GetRootItem, using GetItemType, GetChildCount, GetChildKey and GetChildItem. Each object, array and value is added to the TreeView with its type and value. Edit the JSON and parse it again to see the result; invalid JSON displays the error returned by LoadString.
GetItemByPath
Finds a single item directly by its path, such as /vendor/name or /targets/2/type. Array positions in a path are 1-based.
Generate JSON
Builds a new JSON document in code with JSONGenerator: CreateJsonObject, then AddItemString, AddItemNumber, AddItemBoolean, AddItemDateTime, AddItemNull, AddItemArray and AddItemObject, and finally GetJsonString.
Use as Input
Copies the generated JSON into the input box and parses it, so you can see the round trip.

JSONParser was introduced in PowerBuilder 2017 R2 and JSONGenerator in PowerBuilder 2017 R3.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
