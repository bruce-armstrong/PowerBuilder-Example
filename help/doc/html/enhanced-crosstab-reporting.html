Enhanced Crosstab Reporting

This example features a crosstab with multiple rows, columns, values.

In the default crosstab, click Change Crosstab to change the columns and rows. In the Crosstab dialog box, you can drag columns between the column, row, and value boxes.

The DataWindow has a horizontal split scroll that sets itself to the end of the columns. You can use this control to scroll the right side of the DataWindow while maintaining the titles on the left hand side.
