PDF Builder

This example creates PDF files from PowerScript with the PDF Builder objects, and also exports a DataWindow with the built-in NativePDF engine. Files are saved in your TEMP folder, and you are asked whether to open them.

Build PDF with PDF Builder
The of_build_pdf function creates a PDFDocument with a cover page made of PDFText and PDFMultilineText objects (AddContent, AddPage), then adds the DataWindow with ImportDataWindow. It sets the document Title, Author and Subject through Properties and saves the file with Save.
Protect / Do not allow printing or copying
When checked, the PDF is created with a user password (Security.UserPassword) and/or with printing and copying turned off (Security.AllowPrint and Security.AllowCopy, which require a Security.MasterPassword).
DataWindow SaveAs NativePDF
Exports the DataWindow in one step: Modify("DataWindow.Export.PDF.Method=2") selects NativePDF, then SaveAs(file, PDF!, True) writes the file. No Ghostscript or printer driver is needed.

The PDF Builder objects were introduced in PowerBuilder 2022 and extended in later releases (images, tables of contents, watermarks, attachments and more).

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
