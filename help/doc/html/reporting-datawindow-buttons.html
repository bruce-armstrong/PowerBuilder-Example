Reporting with DataWindow Buttons

This example is a simple report. The toolbar at the top of the window is built with DataWindow buttons.

The button actions are (left to right): Retrieve, Filter, Sort, Print Preview, Print, Save As, First Page, Previous Page, Next Page, Last Page, Help, and Exit. The processing for all buttons except Help and Exit is predefined and requires no code in the window. The action of those two buttons is defined as User Defined which results in the ButtonClicked event of the DataWindow control being fired when they are clicked. The DWObject argument of the event is then checked to determine which button was clicked, and the appropriate action is taken.
