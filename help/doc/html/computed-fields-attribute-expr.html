Computed Fields in Attribute Expr.

The minimum and maximum salaries per department are listed at the end of each group.

To locate the employees in each department with minimum and maximum salaries, use the salary column to match up the text colors. If the employee's salary is the minimum salary for the department, the text color of the salary column is blue. If the employee's salary is the maximum salary for the department, the text color of the salary column is red.

Try changing an employee's salary lower than the current minimum salary or higher than the current maximum salary, and observe the text color changes.
