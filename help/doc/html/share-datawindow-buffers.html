Share DataWindow buffers

The window contains a basic employee DataWindow, with subsidiary DataWindows on the pages of a Tab control for less frequently used information and addresses. Three updateable DataWindows share one primary data source using the ShareData function. Any retrieves made to the primary DataWindow update the secondary DataWindows. Also, any updates to secondary DataWindows update the primary DataWindow store.

Another technique shown is using a Tab control to reduce the clutter of the screen with data and options that are not normally used.

This example also uses the PowerBuilder DataWindow GroupBox.
