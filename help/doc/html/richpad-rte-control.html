RichPad RTE Control

This example uses the Rich Text Edit (RTE) control to create a simple word processor.

All the expected menu options are available with the following additions:

Send
This option is on the File menu. It uses MAPI commands to send the Rich Text document as an attachment to a mail message.
Insert Customer Data Field
This option inserts a data field into the document. The data comes from a DataStore with data from the customer table. This allows mail merge capability.

The toolbar options on the RTE control work like those on many popular word processing programs.
