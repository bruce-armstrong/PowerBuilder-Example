Multiple Toolbars

This example demonstrates how to use PowerBuilder toolbar functionality.

Open a sheet and notice that the toolbar sections are all separate toolbars. You can arrange them separately by either dragging them or by clicking Windows > Toolbars. The Edit menu options (Cut, Copy, and Paste) are in a drop-down toolbar. When you exit, the toolbar positions are saved to either the example.ini file or to the registry, and restored the the next time this example is run.
