Sort and Filter

Click Retrieve to populate the DataWindow.

To change the column on which to sort, choose an item in the DropDownListBox titled, Sort On Column. Choose Ascending or Descending to set the sort order.

Under Filter Column, choose a or type a column name in the left DropDownListBox, and an operator in the middle control. This makes available in the right control a list of unique values from the DataWindow that match your criteria. Choose a value in the right control to complete the expression. For example, last name < m'

The buttons along right side of the window perform basic row functions, like inserting and deleting rows, and updating the database.
