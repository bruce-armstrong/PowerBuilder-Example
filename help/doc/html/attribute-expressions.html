Attribute Expressions

Select the region for which you want to allow modifications to the sales orders. All columns that can be modified have a white background. All columns that are protected have a grey background.

Insert Row
Inserts a new sales order for the region that was specified. The region column becomes protected and automatically set to the region that was specified.
Delete Row
Deletes the current sales order, if it is a sales order in the region that can be modified.
Update
Apply changes to the database.
