RESTClient and HTTPClient

This example calls a public REST API with the native RESTClient and HTTPClient objects. It uses the free test service at jsonplaceholder.typicode.com, so it requires internet access. You can type another URL to try a different service.

RESTClient.Retrieve
Sends a GET request and loads the JSON response straight into the DataWindow with Retrieve(dw, url). The DataWindow columns (id, name, username, email, phone, website) have the same names as the JSON keys, which is how RESTClient maps the data.
HTTPClient GET
Sends the request with SendRequest("GET", url) and shows the status code (GetResponseStatusCode), the response headers (GetResponseHeaders) and the raw body (GetResponseBody).
HTTPClient POST JSON
Builds a JSON body with JSONGenerator, sets the Content-Type header and posts it with SendRequest("POST", url, json). The id the server assigns to the new record is read from the response with JSONParser.
RESTClient.SendGetRequest
Shows the simplest way to get a response body as a string with RESTClient.

RESTClient and HTTPClient were introduced in PowerBuilder 2017 R2. Use RESTClient for simple RESTful APIs with flat JSON, and HTTPClient when you need full control of the request or the response is more complex.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
