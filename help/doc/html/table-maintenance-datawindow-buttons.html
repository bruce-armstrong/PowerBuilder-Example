Table Maintenance with DataWindow Buttons

This example is a simple add/update/delete maintenance window for the contact table.

The record scrolling buttons (First Page, Previous Page, Next Page and Last Page) as well as the Add, Delete and Save buttons are all predefined. The processing for them is built into the DataWindow. The Close and Help buttons are User Defined, which means the ButtonClicked event of the DataWindow control is fired when they are clicked. The DWObject argument of the event is then checked to determine which button was clicked and the appropriate action taken.
