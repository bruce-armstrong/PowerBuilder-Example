ImportString() & RowsCopy()

This example retrieves data in the top DataWindow from the database.
Undo Changes
Make changes in the top DataWindow. When you click Undo Changes, the DataWindow is cleared, and ImportString() is used to import a copy of the data in the DataWindow as it was when this window opened.
Copy DataWindow
When you click Copy DataWindow, the bottom DataWindow is cleared out, and RowsCopy() is used to copy the data from the top to the bottom. The bottom DataWindow contains a DropDownDataWindow, which must be retrieved since the parent DataWindow was reset.
