Stored Procedure Source Data Pipeline

You can use a Stored Procedure as the source for a Data Pipeline.

This example uses a Data Pipeline to create and load a new table that includes all information about a Sales Order. The table consists of data from several other tables. Click the Execute Pipe button to create and load the new table, and display any errors that occur. As the pipe executes, the number of rows read and written is displayed. When it is done, the DataWindow shows the data from the new table.

This example includes both Stored Procedure source and SQL Query source pipelines, so that you can see the difference.
