WebBrowser Control

This example uses the WebBrowser control, which embeds a modern Chromium-based browser (Microsoft Edge WebView2), and shows how PowerScript and JavaScript in the page can call each other. The Microsoft Edge WebView2 runtime must be installed.

Go, Back, Fwd
Navigate with Navigate, GoBack and GoForward. The TitleTextChanged event writes each page title to the log.
Demo
Loads an HTML page from a string with NavigateToString. Its button calls window.webBrowser.ue_from_js(message) in JavaScript, which runs the ue_from_js user event of the control in PowerScript; the string the event returns is shown in the page. The event is registered with RegisterEvent("ue_from_js") in the NavigationStart event, after the browser has finished initializing.
EvaluateJavascriptSync
Runs the JavaScript in the text box in the current page and logs the result, which is returned as a JSON string containing the type and value. After clicking Demo, the script changes text in the page.

A user event called from JavaScript must not call Navigate or EvaluateJavascriptSync itself.

The WebBrowser control was introduced in PowerBuilder 2019 R2.

This example is in PBEXAMNF.PBL, with the other Modern PowerBuilder examples.
