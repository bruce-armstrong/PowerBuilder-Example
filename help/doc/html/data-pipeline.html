Data Pipeline

This example uses the Data Pipeline to:

  • Copy a table structure and data
  • Copy a table structure, no data
  • Execute a transaction - master update

When you open this window or click the Reset Example button, a transaction and master employee tables are created and populated using Data Pipelines. The transaction table is used to update the master table of employees and benefits

Transaction/Master Process
The employee rows in the transaction table are updates that are applied to the master table. Any new employees in the transaction table are added to the master table.
Starting the Pipeline
To follow the process of the Data Pipeline update, select an employee in the transaction DataWindow (on the left side). If the selection is not a new employee, its corresponding row in the master DataWindow (on the right side) is highlighted. To execute the Data Pipeline, selecting the employee's Department and click Execute. Notice that the two highlighted rows now match.
Error Handling
If you try to move department 401, the pipeline returns an error, because no department with that id exists in the master table. The Data Pipeline allows you to fix the data in the Pipe Error DataWindow, then click Repair to continue the pipeline.
Cancel
Stops execution at any time during the pipeline process.
