User Object Examples

This window contains six user objects. Each user object encapsulates its functionality, so using them in a window requires little coding.

Enter a valid Friday
Checks to see if the date entered is a Friday. If not, sounds a beep and clears the date.
Enter a valid numeric
Allows only numeric characters to be entered.
Overtype mode SLE
This SingleLineEdit user object allows characters to be inserted in overtype mode, instead of the standard insert mode.
Numeric Range Checker
Allows numbers to be entered only within the specified range. If the number is not in the specified range, an error message is returned.
Date Scroller
Scrolls the entire date by one day. With standard spin controls, only the portion of the date that is being edited scrolls.
Progress Meter
Updates the width of the status bar and changes the percentage complete, using a user object function.
