MAPI Mail - Send Mail

This example only works with MAPI mail systems. It constructs a letter and allows you to send it to someone on the mail system. The PowerBuilder example communicates directly with your mail system. It sends a DataWindow attachment in the letter in the format of a PSReport file (PSR) file.

Instructions

Select an address from the mail system and click Send to open the mail system's native address selection window. Enter the subject and message, then select a DataWindow. Other options include a receipt upon delivery.

Deprecated

MAPI mail is deprecated, and the MAPI examples are planned for removal. MAPI needs a MAPI mail client such as classic Outlook for Windows, which Microsoft supports until at least 2029. The new Outlook for Windows does not provide MAPI. To send mail from a PowerBuilder application, use the SMTPClient object instead; see Sending Email with SMTPClient.
