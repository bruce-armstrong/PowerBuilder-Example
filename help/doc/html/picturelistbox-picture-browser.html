PictureListBox Picture Browser

This example demonstrates the use of a PictureListBox. It also shows how to display icons on a window using a ListView control.

Enter a directory name for Picture Directory, or click Browse to select one. Under Picture Type, choose SVG images, Bitmaps or Icons, then click Fill PictureListBox to list the available pictures.

SVG images are selected when the example opens, and the directory is the examples' images folder, which holds the SVG icons the examples use. PictureListBox and Picture controls display SVG files at any size without losing sharpness. Choosing Bitmaps or Icons switches to the examples folder, which contains the older bitmaps and icons.

  • To display a picture, select its item in the PictureListBox and click View Picture, or double-click the item. The Picture Zoom window displays the picture in its original size, or, if you choose Size to Fit, the picture changes size when you resize the window.
  • To display an icon, select its item in the PictureListBox and click View Icon, or double-click the item. The View Icon window can display the icon in large (32x32) and small (16x16) sizes.
