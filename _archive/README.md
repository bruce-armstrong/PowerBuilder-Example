# Archived files

Files that the Code Examples no longer use, kept for reference:

- Bitmaps replaced by the SVG icons in `images\` (toolbar, text style, drive/folder, calendar and button glyphs).
- `logo.bmp` and `logo11.bmp`–`logo55.bmp`: a 1990s company logo and the 25 tiles the sliding-picture puzzle was cut from, replaced by `images\puzzle\`.
- `pbexamor.pbl` and `pbexamsa.pbl`: binary libraries for Oracle- and SQL Anywhere-specific examples that are not part of the solution.
- `exam.dat`, `makefile`, `unixmk`: build scripts from the original build process.
- `abapp.wav`, `bm.ico`, `no.cur`, `cprod.bmp`: not referenced by any example.
- `bitmap_pb6.psr`: the PSR Viewer's bitmap gallery as it was, listing the PowerBuilder 6 toolbar bitmaps (most of them archived here). `bitmap.psr` now lists the SVG pictures in `images\`.
- `capb.bmp`, `capw.bmp`, `shortsb.bmp`, `sshirtb.bmp`, `sshirtg.bmp`, `tshirtb.bmp`, `tshirto.bmp`, `tshirtw.bmp`, `visorb.bmp`, `visorw.bmp` and `indicat2.bmp`: the 256- and 16-colour product pictures and row arrow of the saved reports, replaced by new pictures with the same names.
