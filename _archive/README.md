# Archived files

Files that the Code Examples no longer use, kept for reference:

- Bitmaps replaced by the SVG icons in `images\` (toolbar, text style, drive/folder, calendar and button glyphs).
- `logo.bmp` and `logo11.bmp`–`logo55.bmp`: the Powersoft logo and the 25 tiles the sliding-picture puzzle was cut from, replaced by `images\puzzle\`.
- `pbexamor.pbl` and `pbexamsa.pbl`: binary libraries for Oracle- and SQL Anywhere-specific examples that are not part of the solution.
- `exam.dat`, `makefile`, `unixmk`: build scripts from the original Sybase build process.
- `abapp.wav`, `bm.ico`, `no.cur`, `cprod.bmp`: not referenced by any example.
